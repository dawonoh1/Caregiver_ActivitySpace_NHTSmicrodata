Constucting Samples: Household without children and Household with children

=============================================================================

Tour-level Activity Space Construction (Hasanzadeh et al. 2017 approach)

NHTS 2017 | Caregiver travel with/without children

Geographic resolution: Census block-group centroids (from Census TIGER)

Activity space: Minimum Convex Polygon (MCP)

- Home location buffered 100 m

- All other stops buffered 100 m

- Union of buffers → MCP (convex hull)

Outcome: log(area in km²) at the tour level

Required NHTS files (assumed in data_dir):

hhctbg.csv — household home BG

tripctbg.csv — per-trip origin/destination BG

trippub.csv — trip public file (tour ID, child accompaniment flags)

hhpub.csv — household public file (household-level controls)

perpub.csv — person public file (person-level controls)

=============================================================================

2. Build household-level child count (numu10inhh)

Mirrors the Python logic in us_data_processing_1.rmd:

numu10inhh = YOUNGCHILD (ages 0–5 from NHTS HH variable)

+ num_5_9 (ages 5–9 counted from perpub roster)

YOUNGCHILD is a household-level variable already in trippub/perpub.

Children under 5 are NOT in the perpub roster; YOUNGCHILD captures them.

Children 5–9 ARE in the perpub roster via R_AGE_IMP.

—————————————————————————

# Count ages 5–9 per household from perpub roster
hh_5_9 <- perpub %>%
  mutate(age = as.integer(R_AGE)) %>%    # perpub uses R_AGE; R_AGE_IMP is only in trippub
  filter(!is.na(age)) %>%
  group_by(HOUSEID) %>%
  summarise(num_5_9 = sum(age >= 5 & age <= 9), .groups = "drop")
 
# YOUNGCHILD: household-level count of ages 0–5, lives in hhpub (not trippub)
hh_youngchild <- hhpub %>%
  select(HOUSEID, YOUNGCHILD) %>%
  distinct(HOUSEID, .keep_all = TRUE) %>%
  mutate(YOUNGCHILD = as.integer(YOUNGCHILD),
         YOUNGCHILD = replace_na(YOUNGCHILD, 0L))
 
# Combine: numu10inhh = YOUNGCHILD + num_5_9
hh_child_count <- hh_youngchild %>%
  left_join(hh_5_9, by = "HOUSEID") %>%
  mutate(
    num_5_9    = replace_na(num_5_9, 0L),
    numu10inhh = YOUNGCHILD + num_5_9

  select(HOUSEID, YOUNGCHILD, num_5_9, numu10inhh)

## 2b. Build household-level child counts across the full 0-17 range
##
##   numu10inhh   = YOUNGCHILD (0-5) + num_5_9   (5-9)   [as before]
##   num_10_17    = count of ages 10-17 from perpub roster
##   total_child_0_17 = numu10inhh + num_10_17
##
##   no_child   : total_child_0_17 == 0   (no children of ANY age 0-17)
##   with_child : numu10inhh >= 1          (has a child 0-9, regardless of
##                whether 10-17 kids are also present)

# Count ages 10-17 per household from perpub roster
hh_10_17 <- perpub %>%
  mutate(age = as.integer(R_AGE)) %>%
  filter(!is.na(age)) %>%
  group_by(HOUSEID) %>%
  summarise(num_10_17 = sum(age >= 10 & age <= 17), .groups = "drop")

# Combine with your existing numu10inhh (0-9) build
hh_child_count_full <- hh_child_count %>%           # from your original 2b: HOUSEID, YOUNGCHILD, num_5_9, numu10inhh
  left_join(hh_10_17, by = "HOUSEID") %>%
  mutate(
    num_10_17         = replace_na(num_10_17, 0L),
    total_child_0_17  = numu10inhh + num_10_17
  )
## ---------------------------------------------------------------------------
## 2c. Classify households into comparison groups
##     no_child   : total_child_0_17 == 0   (no kids 0-17 at all)
##     with_child : numu10inhh >= 1          (has a child 0-9; 10-17 kids OK too)

##      group and are dropped from the comparison sample)

      total_child_0_17 == 0 ~ "no_child",
      numu10inhh >= 1       ~ "with_child",
      TRUE                  ~ NA_character_   # only-10-17-kids HHs -> excluded
    )
  )

Constucting Activity Spaces

=============================================================================

Daily (person-level) Activity Space — No-child vs With-child(0-9) households

Buffers built from ACTUAL block group polygons, not centroids

Home -> 100 m buffer around BG polygon boundary

Each destination -> 100 m buffer around its BG polygon boundary

Union all buffers (dedup by GEOID) -> convex hull -> area in km^2

CRS: EPSG:5070 (NAD83 Conus Albers, metres, equal area)

=============================================================================

## 4a. Compute daily MCP area from BUFFERED CENTROIDS
##    (now using the fully size-restricted-less than 1sqkm- person-day set)
##    Home centroid       -> 500 m buffer
##    Destination centroid(s) -> 140 m buffer
##    Union all buffers -> convex hull -> area in km^2
##    CRS: EPSG:5070 (NAD83 Conus Albers, metres, equal area)
## ---------------------------------------------------------------------------
CRS_PROJ <- 5070

compute_daily_mcp_area_centroid <- function(geoid_vec, role_vec) {
  pts <- tibble(geoid = geoid_vec, role = role_vec) %>%
    left_join(bg_centroids, by = c("geoid" = "GEOID")) %>%
    filter(!is.na(lon), !is.na(lat))

  if (nrow(pts) == 0) return(NA_real_)

  pts_sf <- st_as_sf(pts, coords = c("lon", "lat"), crs = 4326) %>%
    st_transform(CRS_PROJ)

  buf_dist     <- if_else(pts_sf$role == "home", 500, 140)
  pts_buffered <- st_buffer(pts_sf, dist = buf_dist)

  mcp <- st_convex_hull(st_union(pts_buffered))
  as.numeric(st_area(mcp)) / 1e6   # km^2
}
